# Portfolio web – Tran Quang Khanh

Trang web một trang, không cần cài đặt hay build. Mở `index.html` là xem được.

## Cấu trúc ảnh Stage 02 (@anh.cayy)

- `assets/anhcay/main-couple.jpg`: ảnh "Meet the cast" đầu Stage 02.
- `assets/phone/`: ảnh chụp màn hình trong khung điện thoại (thêm `<figure class="slide">` trong `index.html` và chú thích trong mảng `caps` ở `main.js`).
- `assets/anhcay/cinema/`: loạt ảnh rạp phim (carousel).
- `assets/anhcay/video/`: clip animation raw.
- `assets/anhcay/art/`: gallery tranh (thêm `<figure class="m-item">` trong `index.html`).

Ảnh nên dưới 500 KB mỗi file để trang tải nhanh.
